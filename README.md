# 👗 Chic-Fashion - Modern E-Commerce Landing Page

A visually stunning and responsive fashion landing page designed to showcase the latest trends. This project focuses on high-quality UI/UX, modern typography, and a clean layout to provide a premium shopping experience.

---

### 🚀 Live Demo
[https://kasarshravani04.github.io/Chic-Fashion/]

### 🛠️ Tech Stack
<p align="left">
  <img src="https://skillicons.dev/icons?i=html,css,vscode,figma" />

- **HTML5:** Semantic markup for structured content.
- **CSS3:** Custom styling, Flexbox/Grid layouts, and smooth hover effects.
- **Design Philosophy:** Minimalist, high-fashion aesthetic.

---

### ✨ Key Features

- **Responsive Design:** Optimized for various screen sizes, ensuring a seamless experience from mobile to desktop.
- **Elegant UI:** Features a curated hero section, featured collections, and a stylish footer.
- **Optimized Assets:** Uses a dedicated `assets` folder for high-quality imagery to maintain fast load times.
- **Clean File Structure:** Organized styles and assets for easy maintainability.

---

### 📂 Project Structure
- `index.html` - The main entry point of the website.
- `/styles` - Contains all CSS files for layout and design.
- `/assets` - A dedicated directory for all brand images and icons.
